# Smart PDF Scanner & E-Signature App

## GitHub တွင် APK တည်ဆောက်နည်း
1. ဤ ZIP ဖိုင်ကို ဖြည် (Extract) ပါ။
2. GitHub တွင် Repository အသစ်တစ်ခု ဖန်တီးပြီး ဖိုင်အားလုံးကို Upload တင်ပါ (`.github` folder အပါအဝင် တင်ရန်လိုအပ်ပါသည်)။
3. Repository ၏ **Actions** tab သို့သွားပါက APK ဖိုင်ကို အလိုအလျောက် တည်ဆောက်ပေးနေသည်ကို တွေ့ရပါမည်။
4. Build ပြီးဆုံးပါက **Artifacts** အောက်ရှိ `release-apk` ကို နှိပ်၍ APK ဖိုင်ကို ဒေါင်းလုဒ်ရယူနိုင်ပါသည်။
